# Fordring 文档

Fordring，全称 Tirion Fordring，是一个面向 Java 运行时诊断的 Arthas 集中管理平台。

命名来源：Tirion Fordring 是杀死 Arthas 的人。

- [前端开发设计文档](./frontend-development-design.md)：基于原型图整理的前端技术栈、组件化、依赖库和交互设计。
